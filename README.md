# Ar-terrein

3D-terreinkaart (Terrein3D): gebied kiezen op een kaart (MGRS), daarna 3D met AHN-hoogtes, hoogtelijnen, bos, kenmerken, zichtbereik, meten, weer/zon/maan, AR op tafel en veld-AR, export naar GPX en STL.

Open `index.html` via GitHub Pages (https) zodat AR, camera en GPS werken.

## KamerScan

`kamerscan/` – scan een kamer met de camera (WebXR/ARCore): vloer, hoeken, plafondhoogte, deuren en ramen → 3D-model + plattegrond, export naar GLB/OBJ voor Blender. Open via GitHub Pages: `/kamerscan/`.
